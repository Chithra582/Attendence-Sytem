# Attendance Roster Auditor Skill

## Overview
Evaluates class roster records and session timestamps to verify attendance headcounts and compute percentage presence.

## Operations
1. Ingests student roster records with current session statuses.
2. Calculates totals: Present, Absent, Late, Excused.
3. Computes class attendance rate and formats executive summary.
